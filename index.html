📊 ฐานข้อมูลออนไลน์ Google Sheets

⚪ ยังไม่ได้เชื่อมต่อ

ใส่ Web App URL ที่ได้จากการ Deploy Google Apps Script เพื่อบันทึกข้อมูล ยืม-คืน, สมาชิก, อุปกรณ์ ขึ้นชีตแบบเรียลไทม์

📖 วิธีเอา Web App URL จาก Google Sheets
  1. เปิด Google Sheets ใหม่ > เมนู ส่วนขยาย (Extensions) > Apps Script
  2. วางโค้ดจากไฟล์ google-apps-script/Code.gs แล้วกดบันทึก
  3. กดปุ่มสีน้ำเงิน ทำให้ใช้งานได้ (Deploy) > การทำให้ใช้งานได้ใหม่ (New deployment)
  4. เลือกประเภท เว็บแอป (Web app) > ตั้งค่า ผู้มีสิทธิ์เข้าถึง (Who has access): ทุกคน (Anyone) ***สำคัญมาก
  5. กดปุ่ม ทำให้ใช้งานได้ แล้วคัดลอก URL เว็บแอป (ที่ลงท้ายด้วย /exec) มาวางในช่องด้านบน

💾 สำรองและกู้คืนฐานข้อมูล

📦 สำรองข้อมูลระบบ (Export JSON)

ดาวน์โหลดไฟล์สำรองข้อมูลทั้งหมด (รายการอุปกรณ์, ประวัติการยืม-คืน, สมาชิกนักเรียน, การตั้งค่า) เพื่อเก็บไว้ป้องกันข้อมูลสูญหาย

📂 กู้คืนข้อมูล (Import JSON)

เลือกไฟล์สำรอง (.json) ที่เคยส่งออกไว้ เพื่อนำข้อมูลทั้งหมดกลับคืนสู่ระบบ

⚠️ รีเซ็ตข้อมูลเริ่มต้น

คืนค่าอุปกรณ์และการตั้งค่าเป็นค่าเริ่มต้น
