# 🏀 ระบบยืม-คืนอุปกรณ์กีฬาโรงเรียน (School Sports Equipment Loan System)

> เว็บแอปพลิเคชันจัดการระบบยืมและคืนอุปกรณ์กีฬาสำหรับโรงเรียน ใช้งานง่าย ข้อมูลสต็อกอัปเดตเรียลไทม์ พร้อมระบบ **สมัครสมาชิกนักเรียนป้องกันเพื่อนแกล้ง**, **ระบบคืนอุปกรณ์อัตโนมัติด้วยการสแกน QR Code ประจำจุดคืน (ไม่ต้องรอครู)** และรองรับฐานข้อมูลออนไลน์ **Google Sheets** แบบ 100%

---

## ✨ ฟีเจอร์เด่นของระบบ (Key Features)

### 🎒 1. ระบบสมัครสมาชิก & ล็อกอินนักเรียน (Student Registration & Security)
- 📝 **สมัครสมาชิกง่ายและปลอดภัย:** นักเรียนลงทะเบียนด้วย **รหัสนักเรียน**, **ชั้นเรียน/ห้อง** (เช่น ม.3/1) และ **รหัสผ่าน (Password)** ที่ตั้งเอง
- 🛡️ **ป้องกันเพื่อนแกล้ง:** ป้องกันไม่ให้เพื่อนนำรหัสนักเรียนของคนอื่นไปแอบยืมอุปกรณ์
- ⚡ **Auto-fill สะดวก:** เมื่อล็อกอินแล้ว ระบบจะกรอกรหัสนักเรียนและชั้นเรียนลงในฟอร์มยืมอุปกรณ์ให้อัตโนมัติ

### 📍 2. ระบบคืนอุปกรณ์อัตโนมัติ ณ จุดคืน (Self-Service Return Station)
- 📷 **สแกน QR Code หน้าตู้ (ไม่ต้องรอครูกดรับรอง):** เมื่อนำอุปกรณ์มาวางคืนที่ชั้น/ตู้ในห้องพละ นักเรียนเปิดกล้องสแกนป้าย QR Code ที่ติดอยู่ที่ตู้ ระบบจะบันทึกคืนและเพิ่มสต็อกกลับเข้าสู่ระบบทันที
- ⌨️ **ระบบสำรองด้วยรหัสตู้ (Station PIN):** มีรหัสตัวเลขประจำตู้ (เช่น `SP-8899`) ให้นักเรียนพิมพ์กรอกได้ทันที หากกล้องมือถือมีปัญหาหรือไม่สะดวกสแกน
- 🖨️ **พิมพ์ป้าย QR ประจำจุดคืน:** คุณครูสามารถกดปุ่ม **"🖨️ ป้าย QR จุดคืน"** ในหน้าแดชบอร์ด เพื่อสั่งพิมพ์ป้ายโปสเตอร์ QR Code สวยงามนำไปเคลือบติดที่ตู้เก็บอุปกรณ์ได้ทันที

### 📊 3. ฐานข้อมูลออนไลน์ Google Sheets (Cloud Backend)
- 📑 **ดูข้อมูลได้แบบเรียลไทม์บน Google Sheets:** คุณครูสามารถเปิดดูรายการอุปกรณ์, ประวัติการยืม-คืน, และสมาชิกนักเรียนได้โดยตรงบน Google Sheets ทั้งบนคอมพิวเตอร์และมือถือ
- 🔄 **โหมดไฮบริด (Hybrid Offline-Online):** หากยังไม่ได้เชื่อมต่อ Google Sheets ระบบจะทำงานบน LocalStorage ในเครื่องอัตโนมัติ 100%

### 👨‍🏫 4. แดชบอร์ดสำหรับคุณครูผู้ดูแล (Teacher & Admin Dashboard)
- 📈 **สถิติภาพรวม (Live Metrics):** ยอดอุปกรณ์ทั้งหมด, จำนวนที่กำลังถูกยืม, และรายการที่เกินกำหนดคืน
- 📋 **ตารางประวัติการยืม-คืน:** ค้นหา กรองสถานะ และกดรับคืนแทนนักเรียนได้
- ➕ **จัดการอุปกรณ์ (Equipment CRUD):** เพิ่ม ลบ แก้ไข ปรับยอดสต็อก เลือกไอคอน Emoji
- 📥 **ส่งออกรายงาน Excel/CSV:** ดาวน์โหลดประวัติทั้งหมดเป็นไฟล์ `.csv` (รองรับภาษาไทย UTF-8 BOM)
- 🖨️ **พิมพ์รายงานสรุป:** สั่งพิมพ์รายงานประจำสัปดาห์/เดือนได้ทันที
- ⚙️ **ตั้งค่าระบบ:** เปลี่ยนชื่อโรงเรียน, สโลแกน, บัญชีครู, รหัสจุดคืน (Station Code), และ URL Google Sheets

## 🚀 วิธีการติดตั้ง Google Sheets Backend (ใช้เวลาเพียง 1 นาที)

1. เข้าไปที่ [Google Sheets](https://sheets.google.com/) แล้วกดสร้างสเปรดชีตใหม่ (เช่น ตั้งชื่อว่า `ระบบยืม-คืนอุปกรณ์กีฬา`)
2. ไปที่เมนูด้านบน เลือก **ส่วนขยาย (Extensions) > Apps Script**
3. ลบโค้ดเดิมออกทั้งหมด แล้วคัดลอกโค้ดจากไฟล์ [`google-apps-script/Code.gs`](file:///c:/Users/Hp/Desktop/wep%20app%20%E0%B9%80%E0%B8%82%E0%B9%89%E0%B8%A1/google-apps-script/Code.gs) ไปวางทับ แล้วกดบันทึก (Ctrl+S)
4. กดปุ่มสีน้ำเงิน **"การทำให้ใช้งานได้ (Deploy)"** > เลือก **"การทำให้ใช้งานได้ใหม่ (New deployment)"**
5. ตั้งค่าดังนี้:
   - **เลือกประเภท (Select type):** เว็บแอป (Web app)
   - **คำอธิบาย (Description):** ระบบยืมคืนอุปกรณ์กีฬา
   - **ดำเนินการในฐานะ (Execute as):** ฉัน (Me)
   - **ผู้มีสิทธิ์เข้าถึง (Who has access):** ทุกคน (Anyone) *(***สำคัญมาก***)*
6. กดปุ่ม **"ทำให้ใช้งานได้ (Deploy)"** แล้วกดยืนยันสิทธิ์การเข้าถึง (Authorize access)
7. คัดลอก **URL ของเว็บแอป (Web app URL)** (ที่ลงท้ายด้วย `/exec`)
8. เปิดหน้าเว็บระบบยืม-คืนอุปกรณ์กีฬา > ล็อกอินครู (`admin` / `1234`) > กด **"⚙️ ตั้งค่าระบบ"** > วาง URL ในช่อง **"Google Apps Script Web App URL"**
9. กดปุ่ม **"🔍 ทดสอบ"** > จากนั้นกด **"📤 นำข้อมูลในเครื่องขึ้นชีต (Push)"** เพื่อส่งตารางและอุปกรณ์ทั้งหมดขึ้น Google Sheets ทันที!

### 🛠️ วิธีแก้ปัญหาหาก Google Sheets ไม่ทำงานหรือไม่ขึ้นข้อมูล (Troubleshooting Checklist)

หากลองยืม คืน หรือเข้าสู่ระบบแล้ว ข้อมูลใน Google Sheets ยังไม่ขึ้น ให้ตรวจสอบ 4 จุดนี้ตามลำดับ:

1. **ตรวจสอบ URL ที่นำมาใส่:**
   - ❌ **ห้ามนำลิงก์หน้าชีตมาใส่:** เช่น `https://docs.google.com/spreadsheets/d/...` (อันนี้คือลิงก์เปิดดูชีต ไม่ใช่ API)
   - ❌ **ห้ามใช้ลิงก์ที่ลงท้ายด้วย `/dev`:** ลิงก์ `/dev` จะติดระบบรักษาความปลอดภัยของ Google ทำให้เว็บภายนอกส่งข้อมูลไม่ได้
   - ✅ **ต้องใช้ลิงก์ Web App URL ที่ลงท้ายด้วย `/exec` เท่านั้น** เช่น `https://script.google.com/macros/s/AKfycbx.../exec`

2. **ตรวจสอบสิทธิ์ผู้เข้าถึง (Who has access):**
   - ไปที่หน้า Google Apps Script > กดปุ่ม **Deploy (การทำให้ใช้งานได้)** > **Manage deployments (จัดการการทำให้ใช้งานได้)**
   - กดรูปดินสอ ✏️ **Edit** > ตรวจสอบว่า **"Who has access (ผู้มีสิทธิ์เข้าถึง)"** ตั้งเป็น **"Anyone (ทุกคน)"** แล้วหรือยัง *(ถ้าเลือกเป็น Only myself หรือเฉพาะฉัน จะส่งข้อมูลไม่เข้า)*
   - ในช่อง **Version** ให้เลือกเป็น **"New version (เวอร์ชันใหม่)"** เสมอทุกครั้งที่มีการแก้ไขโค้ด แล้วกด **Deploy**

3. **กดปุ่ม "🔍 ทดสอบ" และ "📤 นำข้อมูลในเครื่องขึ้นชีต" ในหน้าเว็บ:**
   - เข้าสู่ระบบครู (`admin` / `1234`) > กด **"⚙️ ตั้งค่าระบบ"**
   - วาง URL แล้วกดปุ่ม **"🔍 ทดสอบ"** (ระบบจะแจ้งเตือนว่าเชื่อมต่อสำเร็จหรือไม่)
   - หากสำเร็จ ให้กดปุ่ม **"📤 นำข้อมูลในเครื่องขึ้นชีต (Push)"** เพื่อส่งข้อมูลที่มีอยู่ทั้งหมดไปสร้างเป็นตารางใน Google Sheets ทันที 1 คลิก!
